1   Introduction

    The primary objective of the R-Type project is to create a multiplayer game supporting up to four players.

3.  R-Type architecture

    The R-Type architecture adopts a client-server model.
    Clients establish an initial connection with the server using the
    defined protocol and subsequently spawn within the game environment.

4. Protocol

    1. Packets

    When a player is activly engaged in the game, communication between the client and server
    occurs through the R-TYPE UDP Protocol. This protocol facilitates the transimission of updates
    related to game entities via UDP.
